El problema a resolver

El reto

Después de finalizar una atracción, es necesario verificar que el vagón se encuentre libre de movimiento antes de permitir un nuevo inicio. Además, el pasajero debe contar con un mecanismo sencillo para generar una alerta de emergencia durante el funcionamiento.

El proyecto busca automatizar esta verificación y establecer una condición de bloqueo cuando se detecta movimiento.

Nuestra propuesta

Nuestra solución

RideLock utiliza un sensor PIR para verificar el movimiento dentro del vagón antes de autorizar un nuevo ciclo. Si se detecta movimiento, el sistema mantiene bloqueado el inicio. Cuando el vagón permanece libre durante el periodo de verificación, el sistema habilita el inicio de la atracción.

Durante el funcionamiento, un botón de emergencia permite al pasajero activar inmediatamente una alerta visual y sonora, bloqueando el sistema hasta que se realice el reinicio correspondiente.

¿Qué aporta RideLock?

  • Verificación automática
  • Bloqueo ante movimiento detectado
  • Indicadores visuales de estado
  • Alerta de emergencia para pasajeros
  • Reinicio controlado

Proceso

¿Cómo funciona?

01

Detección

El sensor PIR verifica si existe movimiento en el vagón.

02

Verificación

Si no se detecta movimiento, comienza una comprobación de 5 segundos.

03

Autorización

Si el vagón permanece libre, el sistema indica que está listo y comienza la cuenta regresiva de inicio.

04

Emergencia

Durante el funcionamiento, el pasajero puede presionar el botón de emergencia para activar una alerta visual y sonora y bloquear el sistema.
